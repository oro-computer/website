## Typography
| Type               | Font                  | Usage                                     | Weight           |
| ------------------ | --------------------- | ----------------------------------------- | ---------------- |
| **Display / Logo** | `Aeonik` or `Satoshi` | Headings, hero text, wordmark “oro”       | Bold / SemiBold  |
| **Body**           | `Inter`               | Paragraphs, documentation, UI copy        | Regular / Medium |
| **Mono (Code)**    | `JetBrains Mono`      | Code blocks, CLI, developer documentation | Regular          |

## Ratios
- `h1`: `48px / 1.1 line-height`
- `h2`: `32px / 1.2 line-height`
- `h3`: `24px / 1.3 line-height`
- `body`: `18px / 1.6 line-height`
- `caption`: `14px / 1.6 line-height`

## Editorial display

Homepage display headings may scale fluidly from 48px to 112px, with a tight
1.0–1.05 line height. Product headings may reach 72px. Keep body copy at 18px,
code at 14px or larger, and supporting labels at 14px or larger. Use the system
fallbacks when the named brand fonts are unavailable; do not depend on a remote
font request for readable content.
