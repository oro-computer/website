## Layout & Composition
- Grid System: 8px baseline, 12-column fluid layout
- Section Padding: 96px desktop / 48px mobile
- Container Width: max 1280px for reading surfaces; max 1440–1600px for homepage and product overview compositions that need a wider editorial canvas.
- Corner Radius: 12px (soft geometric language)
- Shadow Style: 0 4px 16px rgba(0,0,0,0.06) - light and subtle

- Shared horizontal navigation connects the two technology initiatives: Oro Runtime and Silk.
- Homepage: generous typography, a geometric petal study, and two clearly linked product sections.
- Documentation: quiet themed surfaces, a bounded reading column, and separate scrolling navigation.
- Use 24px minimum page gutters (16px on narrow phones), 24–48px component gaps,
  and 96px section spacing on desktop / 48px on mobile. Controls target at least 44px.
- Reading content must reflow at 320px; code and wide tables may scroll within their own bounds.
