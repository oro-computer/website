Oro Runtime

Ship native applications with web code.

Build UI with HTML/CSS, behavior with JavaScript, configure projects with oro.toml, and import native capabilities as explicit ES modules under oro:*. Use oroc to run, build, package, inspect, and publish updates from the same project model.

Read the docs JavaScript APIs CLI GitHub
Common workflow
Start 
hello/
  oro.toml
  copy-map.toml
  src/
    index.html
  main.js
oroc run .
oroc run src/index.html
oroc run src/main.js
oroc build . --platform=ios-simulator
oroc update init

Start from a project directory, a single HTML entry point, or a single JavaScript module.

Programming model

The web platform is the UI toolkit. Oro Runtime adds an explicit capability layer (oro:*) plus a bundling story that feels like shipping a website.

Web standards

DOM, ES modules, fetch, URLs, WebCrypto, WebAssembly, and modern browser APIs — because your app runs inside the platform WebView.
Project layout

Explicit capabilities

Import native functionality as ES modules under oro:*. The public surface spans application and windows, filesystem and process, networking and transport, storage, workers, notifications, MCP, and AI.
Module index

CLI, config, and updates

Define bundle inputs with copy_map, tune behavior in oro.toml and .ororc, then use oroc for setup, packaging, device install, versioning, MCP, and signed update manifests and bundles.
