# All module specifiers

Public, stable module specifiers:

```text
sage:fs
sage:path
sage:process
sage:env
sage:navigator
sage:performance
sage:crypto
sage:uuid
sage:url
sage:core/dom
sage:core/web
sage:fetch
```

Present in the runtime but not part of the stable downstream surface:

```text
sage:core/global
sage:internal/host
```

Use the stable list for plugin code you expect to keep working across releases.
