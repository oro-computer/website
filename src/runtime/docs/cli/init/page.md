# [`oroc init`](/runtime/docs/cli/init/)

Create a new project. If the path is not provided, the new project is created in the current directory.

## Usage

```bash
oroc init [<project-dir>]
```

## Options

| Option | Description |
| --- | --- |
| `-C, --config` | only create the config file |
| `-n, --name` | project name |
