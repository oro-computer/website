# `slcc` (1) — Alias of `silk cc`


## Name

`slcc` — convenience entrypoint for `silk cc`.

## Synopsis

- `slcc <cc args...>`

## Description

`slcc` is an argv0-based alias of `silk cc`. It behaves the same as running:

```sh
silk cc <cc args...>
```

See `silk-cc` (1) for details, including the default `-I`/`-L`/`-lsilk` flags.
