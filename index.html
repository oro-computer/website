Systems software

Build native apps with the web platform.

Oro Runtime embeds the platform WebView and exposes native capabilities to JavaScript as explicit ES modules (oro:*). Silk is a spec-first systems language and compiler toolchain.

Projects

Two pillars: a runtime for app developers and a language/toolchain for systems work.

Oro Runtime

Cross-platform runtime embedding the platform WebView. Native features are imported as ES modules under oro:*, with a CLI (oroc) and TOML configuration (oro.toml).
Runtime docs Overview GitHub

Silk

Spec-first systems programming language and compiler toolchain implemented in Zig, with a C99 embedding ABI (libsilk).
Silk docs Overview Spec (2026)
