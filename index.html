Projects

Three open-source systems that support high-fidelity software under real constraints.

Oro Runtime

Cross-platform runtime embedding the platform WebView. Native features are imported as ES modules under oro:*, with a CLI (oroc) and TOML configuration (oro.toml).
Runtime docs Overview GitHub

Silk

Silk is a high performance general purpose programming language with formal verification built in. Silk targets computer systems, mobile / tablet devices, WASM / WASI runtimes, and the web. Implemented in Zig, with a C99 embedding ABI (libsilk).
Silk docs Overview Spec (2026)

Sage

Sage is a fast, ergonomic terminal pager for files, directories, stdin, and remote content. It includes syntax highlighting, cross-tab search workflows, and a robust JavaScript plugin runtime.
Sage docs Overview GitHub
